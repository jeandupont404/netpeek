About DNS Lookup

Use NetPeek's free DNS lookup tool to see exactly which DNS records are published for any domain. This is useful for troubleshooting website issues, verifying that a domain is correctly configured, checking mail server settings, or inspecting a domain before connecting to it.

Frequently Asked Questions

What is a DNS lookup?

A DNS lookup translates a human-readable domain name into the records that point to its servers. This tool queries the Domain Name System and returns the DNS records associated with any domain, including A, AAAA, CNAME, MX, NS and TXT records.

How do I perform a DNS lookup?

Enter any domain name in the field above and click Lookup DNS. NetPeek instantly returns all A, AAAA, CNAME, MX, NS and TXT records for that domain, powered by Google DNS-over-HTTPS. No signup required.

What are the different DNS record types?

A records map a domain to an IPv4 address, AAAA records map to IPv6, CNAME records alias one domain to another, MX records define mail servers, NS records specify authoritative name servers, and TXT records hold arbitrary text such as SPF or verification strings.

Is this DNS lookup tool free?

Yes. NetPeek's DNS lookup tool is completely free, with no signup, no account and no limits. It queries public Google DNS-over-HTTPS servers to return results instantly.
